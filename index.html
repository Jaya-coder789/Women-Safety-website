About Women Safety Web

The Women Safety Website is an intuitive, smart emergency web application developed to assist women during critical situations. Features include quick SOS alerts, live geolocation dispatch, simulated fake calls to evade uncomfortable scenarios, and direct access to police and medical helplines.

Developer: Jaya Bhunte Project

Tech Stack: HTML5, CSS3, JavaScript ES6, Web Geolocation API, Web Audio API
